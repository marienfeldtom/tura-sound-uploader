# 7secs – Torsong Soundboard & Management

Web-Anwendung und REST-API zur Verwaltung und Bereitstellung von individuellen 7-Sekunden-Torsongs für Handball-Mannschaften und Hallen-Soundboards.

---

## 📱 Dokumentation für Mobile Apps & Entwickler

- 📖 [**API Dokumentation**](API_DOCUMENTATION.md) – Alle REST-Endpunkte, JSON-Payloads, 7-Sekunden-Timing-Logik, Caching-Strategien und Code-Beispiele (Swift, Kotlin, Flutter).
- 🎨 [**Mobile App Design System & Style Guide**](APP_DESIGN_SYSTEM.md) – Farb-Tokens, Typografie, 4pt/8pt Spacing-Grid, Soundboard-Komponenten, Zustände (Idle/Playing) und native Code-Snippets (SwiftUI / Jetpack Compose).

---

## 🚀 Lokale Entwicklung

```bash
# Abhängigkeiten installieren
npm install

# Entwicklungsserver starten
npm run start:dev

# Tests ausführen
npm test
```

Standardmäßig läuft die Web-App und API auf `http://localhost:3000`.
